# Me Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the LarpedIn Me page — a full single-column profile page at `/me` with 8 sections, fake edit controls, and LarpedIn-exclusive Larp History.

**Architecture:** Feature folder `src/features/me/` following the same pattern as `src/features/home/`. Each section is its own sub-folder with JSX + CSS Module. `Me.jsx` is the top-level page that composes all sections. All data comes from `useMockData()` (`currentUser`); section-specific mock content (Experience, Education, Skills, Larp History, Glazes) is defined as static constants within each component file.

**Tech Stack:** React, Vite, CSS Modules, Vitest + React Testing Library, React Router v6
